# Contributing to this Project

Thank you for your interest in contributing! As an open-source project, welcome contributions from the community. To maintain code quality and ensure legal safety for everyone, please follow these guidelines.


## Legal & Licensing

By contributing to this project, you agree that your contributions will be licensed under the **Apache License 2.0**. You must ensure that you have the right to submit the code and that it does not violate any third-party copyrights or patents.


## How to Contribute

### Bugs

If you found a bug, please open an issue.


### Improvement

Before submitting changes, please open an issue an let's talk about it.


### Testing

The functionality of all new features *must* be checked by unit tests.


### Submitting changes

1. **Fork the Repository:** Create your own fork of the project.
2. **Create a Branch:** Use a descriptive name for your branch (e.g., `feature/login-system` or `fix/button-glitch`).
3. **Write Clean Code:** Follow standard coding practices, include comments, and ensure all existing tests pass.
4. **Submit a Pull Request:** Describe your changes clearly in the PR template.


## AI-Generated Code Guidelines

We allow the use of AI assistants (like GitHub Copilot, ChatGPT, or Claude) to help write code, but we require all contributors to follow these strict rules to protect the project from licensing and security risks:

* **Meticulous Review:** You are fully responsible for any AI-generated code you submit. Never blindly copy-paste.
* **No Plagiarism:** Since we do not run automated plagiarism filters, you must ensure the AI did not reproduce copyrighted code from other projects.
* **Testing Required:** All AI-generated logic or functions must be accompanied by comprehensive unit tests to prevent AI "hallucinations" and bugs.
* **Transparency:** If a Pull Request contains significant amounts of AI-generated code, please state it clearly in the PR description (e.g., using an "AI-assisted" note).


## Code Quality & Security

* Do not submit outdated or insecure API patterns often generated by AI models.
* Ensure your code does not contain hardcoded credentials, API keys, or personal data.
* Every Pull Request must pass the automated build checks (if applicable) and will be reviewed before merging.
