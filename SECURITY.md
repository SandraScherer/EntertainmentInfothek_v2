# Security Policy

## Supported Versions

Since this project is intended for educational purposes and is still in its early stages, security updates are provided only for the latest version.

| Version | Supported          |
| ------- | ------------------ |
| newest  | :white_check_mark: |
| other   | :x:                |


## Reporting a Vulnerability

Please don’t publish details in a public issue or PR, please use the private vulnerabilty reporting feature of GitHub.
